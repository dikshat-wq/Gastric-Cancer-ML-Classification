# Gastric-Cancer-ML-Classification
Machine learning-based classification of gastric cancer using differentially expressed genes from gene-expression data. This project focuses on generating classifier models like Logistic Regression, ANN and SVM which distinguishes between gastric cancer and normal tissues based on the gene expression levels.
Objectives:
Analyze gene-expression data from the Gene Expression Omnibus (GEO).
Identify significantly upregulated and downregulated genes.
Develop machine learning models for cancer-versus-normal classification.
Evaluate model performance using standard classification metrics.
